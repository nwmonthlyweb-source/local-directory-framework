# Local Directory Framework

Reusable WordPress directory framework for NW Monthly.

## Initial Website

- Domain: nwmonthly.com
- Brand: Northwest Monthly Directory
- Region: Oregon
- Public visitors do not need accounts.
- Business changes use reviewed request forms.
- Paid placements remain separate from editorial rankings.

## Initial Visitor Flow

Intro → Category → State → City → Specialty → Top 10 Results → Business Profile

## Initial Categories

- Contractors
- Realtors
- Restaurants

## Initial Cities

- Portland
- Beaverton
- Hillsboro
- Lake Oswego
- Gresham

## Planned Features

- Structured business records
- Categories, specialties, states, and cities
- Conditional directory navigation
- Public business profile pages
- Monthly Top 10 ranking snapshots
- Research sources and verification history
- Add, update, correction, claim, and removal requests
- Admin approval workflow
- Sponsored placement and bottom-banner advertising
- Import and duplicate-detection tools
- Cache-friendly public pages
